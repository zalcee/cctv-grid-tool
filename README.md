## CCTV-grid-Tool

### Requirement
* Python

### Installation

1. Download the cctv-grid-tool in github
2. open cmd and find the tool location
3. run "pip install -r requirements.txt"  to install the necessary packages.
4. Open .env file and change the credential
4. Run "py main.py" it will generate the collage pic and the retention days.

Note: for dahua change the channels format to 1,2,3,4 instead of 101,102,103
